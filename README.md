1) https://nodejs.org adresinden Node.js (LTS) kurun.
2) Bu klasörü açın ve build.bat dosyasına çift tıklayın.
3) İşlem bitince "dist" klasöründe şunlar olur:
   - Kuduko Müzik Yapım Setup 1.0.0.exe  (kurulum dosyası)
   - Kuduko Müzik Yapım 1.0.0.exe        (kurulum gerektirmeyen taşınabilir sürüm)
Test için sadece çalıştırmak isterseniz: npm install ve ardından npm start
